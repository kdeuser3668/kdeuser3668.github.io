Resources

The following resources were used to develop and support the content on this website. These sources provide reliable information on web development, programming fundamentals, and best practices in Information Technology.

1. Mozilla Developer Network (MDN Web Docs)

Mozilla. (n.d.). HTML: HyperText Markup Language. https://developer.mozilla.org/en-US/docs/Web/HTML

This website is included because it is one of the most trusted and widely used references for learning HTML, CSS, and JavaScript. It provides clear explanations and examples for beginners.

2. W3Schools

W3Schools. (n.d.). CSS Tutorial. https://www.w3schools.com/css/

W3Schools is used as a beginner-friendly learning tool for understanding CSS styling concepts such as colors, layouts, and responsive design.

3. freeCodeCamp

freeCodeCamp. (n.d.). Responsive Web Design Certification. https://www.freecodecamp.org/learn/

This resource provides hands-on coding practice and structured lessons that help learners build real-world web development skills.

4. Google Fonts

Google. (n.d.). Google Fonts Library. https://fonts.google.com/

Google Fonts is used to enhance website typography and improve readability and visual design.

5. Flexbox Guide (CSS-Tricks)

CSS-Tricks. (n.d.). A Complete Guide to Flexbox. https://css-tricks.com/snippets/css/a-guide-to-flexbox/

This guide is included because Flexbox is a key layout tool in modern web design, helping developers create responsive and structured page layouts.
